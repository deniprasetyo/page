Halaman contoh
untuk GitHub Pages

Ganti isi file ini dengan kontenmu sendiri — profil, portofolio, dokumentasi proyek, atau apa saja. File ini hanya untuk menunjukkan bagaimana HTML, CSS, dan JS bekerja sama saat di-hosting di GitHub Pages.

Lihat cara kerjanya

Tiga file, satu situs

HTML

index.html

Berisi struktur & isi halaman. GitHub Pages selalu mencari file ini sebagai halaman pembuka.

CSS

style.css

Mengatur tampilan: warna, jarak, tipografi, dan tata letak seperti yang kamu lihat di halaman ini.

JS

script.js

Menambahkan interaksi kecil — coba klik tombol penghitung di bawah.

Coba interaksinya

Tombol ini dikendalikan oleh script.js — bukti bahwa JavaScript berjalan di situs yang kamu hosting.

Dibuat sebagai contoh belajar GitHub Pages.
